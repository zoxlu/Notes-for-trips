## Day5（四）

犬山來回加爬天守閣（階梯陡），也許體力消耗會比較大。

| 時段 | 安排 | 備註 |
|---|---|---|
| 上午 | [[犬山城]]（順遊 [[三光稲荷神社]]） | 名鐵約30分鐘 |
| 午餐 | 犬山城下町（[[木曽川商店（犬山城下町烤香魚）]]、[[本町茶寮]]、[[犬山牛太郎（飛驒牛握壽司）Inuyama Gyutaro]]） | |
| 點心 | [[犬山ぐーまる（栗子蒙布朗）]]、[[山田五平餅店]] | 本町通甜點街，秋季限定栗子蒙布朗霜淇淋；五平餅店為國家登錄有形文化財建築 |
| 下午 | 回市區，[[榮商圈]] 逛街 | |
| 晚餐（暫定） | [[鳥開總本家]] | 名駅エスカ店，親子丼溫和好入口，適合走累的時候 |
